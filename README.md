# CWA Local 4603 – Modernized Website Files

These files are a cleaner, multi-page version of the current cwa4603.org site. All original important information is preserved and categorized for easier navigation. Older contracts are included under “Past Contracts.”

## Files included
- `index.html` – Home page with quick links
- `meetings.html` – Meetings and election details
- `contracts.html` – Current + past contracts
- `forms.html` – All member forms
- `leadership.html` – Officers, districts, stewards
- `committees.html` – Full committee list
- `retirees.html` – RMO information
- `resources.html` – Scholarships, Wiretap, clothing, useful links
- `style.css` – Shared styling

See the full guide in the original README for Wix import options.
